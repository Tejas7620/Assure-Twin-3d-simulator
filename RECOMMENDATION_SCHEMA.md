# ASSURE-TWIN: Recommendation Contract Schema & Explainability

## 1. Formal Recommendation Contract
Every recommendation generated by ASSURE-TWIN is wrapped in a cryptographically trackable, immutable **Recommendation Contract** (`RecommendationCase`).

### Schema Definition (JSON)
```typescript
interface RecommendationCase {
  caseId: string;                     // e.g. "REC-20260927-BGW17A-4310"
  timestamp: string;                  // ISO 8601 UTC
  wellId: string;                     // "BGW-17A"
  status: "RECOMMENDED" | "ABSTAIN" | "APPROVED" | "REJECTED";
  targetCandidate: string;            // e.g. "Coordinated Joint CSS + SRP"
  setpoints: {
    spm: number;                      // Surface pumping speed
    strokeLengthInches: number;       // Polished rod stroke
    steamVolumeTons: number;          // Proposed steam cycle volume
    steamRateTonsPerDay: number;      // Steam injection rate
  };
  expectedGains: {
    oilDeltaBopd: number;             // Expected incremental oil
    sorImprovement: number;           // Steam-Oil-Ratio delta
    energySavingsKwh: number;         // Avoided parasitic power
  };
  whyChain: string[];                 // 5-step causal physics justification
  whyNotJustifications: {
    option: string;
    reason: string;
  }[];
  assuranceSummary: {
    passedGates: number;              // 12
    totalGates: number;               // 12
    overallPass: boolean;
  };
  engineerReview?: {
    approvedBy: string;
    approvedAt: string;
    notes: string;
  };
}
```

## 2. Dual Explainability Engine

### "WHY" Engine (Causal Physics Lineage)
Rather than presenting black-box numbers, ASSURE-TWIN articulates a transparent 5-step causal narrative:
1. **Steam Transfer**: Injected steam enthalpy transfers heat to the near-wellbore rock matrix.
2. **Rheology Shift**: Thermal energy drops in-situ crude viscosity from $1,840\text{ cP}$ to $< 280\text{ cP}$.
3. **Inflow Stimulation**: Viscosity reduction unlocks heavy crude mobility, increasing Vogel inflow.
4. **Mechanical Load Relief**: Lower fluid drag decreases downstroke resistance, expanding rod float margin.
5. **Production Realization**: Synchronized $2.8\text{ SPM}$ speed and $74"$ stroke capture incremental oil ($+19\text{ BOPD}$) without exceeding rod structural limits.

### "WHY NOT" Engine (Counterfactual Rejection Justifications)
Engineers must understand why alternative actions were rejected:
- **Reject Current (Hold)**: Near-wellbore cooling will induce severe rod float hazard ($M_{float} < 10\%$) within 0-3 days.
- **Reject CSS Only**: Injecting steam without adjusting mechanical stroke risks fluid pound during early cleanup.
- **Reject SRP Only**: Speed derate avoids rod float but sacrifices recovery ($+0\text{ BOPD}$ vs $+19\text{ BOPD}$).
